## Описание проекта

Проект представляет из себя помощника оператора станка 



### Роли

- Артём - Поиск по документации

- Ярослав - Приложение и UI

## Правила:

- каждый работает со своего аккаунта и меняет свою папку;
- чужие и общие файлы изменяем по согласованию;
- основная версия находится в main, изменения добавляем туда после проверки через **pull request — запрос на добавление изменений**;
- задания и вопросы остаются в YouGile, к результату прикладываем ссылку на GitHub.
