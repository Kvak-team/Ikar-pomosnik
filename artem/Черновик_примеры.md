# Черновые примеры запросов оператора

Данные примеры сохранены отдельно для дальнейшей проверки и проработки базы знаний.

### Пример 1
- **Вопрос:** Ошибка зажима на 90°
- **Ответ:** отрегулируйте V-образную направляющую верхнего зажима
- **Источник:** KD500 DL ZL.pdf

### Пример 2
- **Вопрос:** Предельное отклонение для вала h6 размера 10
- **Ответ:** 0 -0.011
- **Источник:** https://tebx.ru/dopuski-posadki/val-h.html

### Пример 3
- **Вопрос:** что делает код G30?
- **Ответ:** Поднятие по оси Z на точку смены инструмента (Пример: G30 G91 Z0)
- **Источник:** https://investsteel.ru/journal/article/sintaksis-g-code / таблица G-кодов

### Пример 4
- **Вопрос:** Как переключить режим работы на работу в метрической системе?
- **Ответ:** G-код G21 отвечает за переключение режима работы в метрическую систему (пример: G90 G21)
- **Источник:** https://investsteel.ru/journal/article/sintaksis-g-code / таблица G-кодов
